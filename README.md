## نظرة عامة

صُمّم **أطلس الحروف** ليجمع الأدوات المتعلقة بالأسماء والحروف في واجهة عربية واحدة تعمل محليًا على Windows. يبدأ التطبيق مباشرة بقسم **الأسماء**، ولا يحتاج إلى إنشاء حساب أو إرسال الأسماء إلى خادم خارجي.

يركّز المشروع على ثلاثة مبادئ:

- إظهار خطوات الحساب بدل تقديم نتيجة غامضة.
- الفصل بين المعلومة التاريخية والحقيقة العلمية.
- الامتناع عن تقديم طقوس، أحجبة، تنبؤات أو ادعاءات غيبية.

## المزايا

### 1. الأسماء واقتراح اسم المولود

- إدخال اسم الأب واسم الأم.
- تجربة اسم يرغب فيه الوالدان وحساب قيمته فورًا.
- عرض قراءة حسابية لعلاقة الاسم ببيانات الوالدين المدخلة.
- قوائم منفصلة لأسماء الذكور والإناث.
- قاعدة محلية تضم أكثر من ٦٠٠ اسم، تشمل الأسماء العربية المعروفة ودفعة منتقاة من الأسماء العصرية المتداولة.
- البحث داخل الأسماء المقترحة.
- اختيار الاسم المقترح بضغطة واحدة لإظهاره في خانة الاسم المرغوب.
- تنبيه واضح بأن المعنى الحسن وآداب التسمية مقدّمان على أي حساب تراثي.

### 2. مقارنة الأسماء

- مقارنة اسمين في لوحة واحدة.
- إضافة اسم الأم لكل شخص بصورة اختيارية.
- عرض مجموع كل اسم والباقي من القسمة على 9.
- عرض الطبائع والمراسلات الحرفية داخل تفاصيل قابلة للتوسيع.
- دمج «الغالب والمغلوب» وعلاقة الطبائع والمقارنة الحرفية في تصميم موحّد.

> [!NOTE]
> «الغالب والمغلوب» والطبائع المعروضة قواعد تراثية حسابية، وليست مقياسًا للعلاقات أو دليلًا لاتخاذ قرارات شخصية.

### 3. حاسبة الجُمَّل

- حساب قيمة النص العربي أثناء الكتابة.
- تفصيل النتيجة كلمةً كلمة وحرفًا حرفًا.
- دعم رقم مستهدف اختياري وعرض مقدار الاقتراب منه.

### 4. الأبراج

يتضمن القسم مسارين منفصلين بوضوح؛ الاسم لا يدخل في حساب خريطة الميلاد:

#### خريطة الميلاد الرمزية

- حساب مواضع الشمس والقمر وعطارد والزهرة والمريخ والمشتري وزحل بالدرجة والبرج.
- حساب الطالع والغارب ووسط السماء وقاعها عند توفر وقت ومكان الميلاد.
- عرض «الثلاثة الكبار»: الشمس والقمر والطالع، مع شرح مفصّل لكل موضع.
- توزيع الكواكب على البيوت الاثني عشر بنظام **Whole Sign**.
- عرض الزوايا الرئيسية: الاقتران والتسديس والتربيع والتثليث والمقابلة.
- عرض حاكم الخريطة وتوازن العناصر والكيفيات وطور القمر والحركة التراجعية الظاهرية.
- عجلة بصرية للخريطة وجدول كامل للمواضع والبيوت.
- تحويل وقت الميلاد المحلي إلى UTC باستخدام المنطقة الزمنية التاريخية للمدينة.
- اختيار مكان الميلاد من قاعدة محلية تضم أكثر من ٢٥٠ مدينة مصرية موزعة على جميع المحافظات؛ ولا تظهر دول أخرى في الواجهة.
- إذا كان الوقت غير معروف، لا يخمّن التطبيق الطالع أو البيوت، وينبه عند احتمال انتقال الشمس أو القمر بين برجين خلال يوم الميلاد.
- تعمل الحسابات محليًا باستخدام Astronomy Engine، ولا تُرسل بيانات الميلاد إلى الإنترنت.

الدرجات والمواضع نتائج فلكية حسابية، أما ربطها بالسمات الشخصية فهو قراءة رمزية تراثية غير مثبتة علميًا.

#### البرج الحرفي التراثي

1. تحويل حروف اسم الشخص واسم الأم إلى قيم الأبجد المشرقي.
2. جمع القيمتين.
3. أخذ الباقي من القسمة على 12؛ إذا كان الباقي صفرًا تُستخدم القيمة 12.
4. المطابقة بالترتيب: 1 الحمل، 2 الثور، حتى 12 الحوت.

يمكن الحساب من الاسم وحده، لكن التطبيق يصف النتيجة بأنها **جزئية**؛ لأن المصدر التراثي الموثّق يذكر الاسم واسم الأم.

يحتوي القسم أيضًا على:

- دليل بصري للأبراج الاثني عشر.
- العنصر والكيفية والكوكب المنسوب تراثيًا لكل برج.
- قراءة رمزية مختصرة لنقاط القوة ومساحات التوازن.
- روابط لمصادر فلكية أصلية وأكاديمية وعلمية ودينية تُفتح في متصفح Windows الافتراضي.
- تحذير دائم من اعتبار النتائج وصفًا علميًا للشخصية أو تنبؤًا بالمستقبل.

### 5. المرجع والمنهج

- جدول الأبجد المشرقي المستخدم في الحساب.
- توزيع الحروف على الطبائع.
- ترتيب الكواكب والبروج المستخدم داخل المراسلات الحرفية.
- زر لاختبارات ذاتية مرجعية.
- إمكانية مسح البيانات المحلية المحفوظة.

## ما الذي لا يقدمه التطبيق؟

- لا يوجد قسم للأوفاق أو إنشاء للمربعات والطلاسم.
- لا توجد تعليمات للسحر أو الأحجبة أو الاستعانة بالجن.
- لا توجد توقعات للحظ أو المستقبل أو الزواج أو الصحة أو المال.
- لا يقدّم توقعات مبنية على خريطة الميلاد ولا يعتبرها حقيقة نفسية.
- لا يعتبر الصفات الرمزية حقائق نفسية أو تشخيصًا للشخصية.

## منهج حساب الجُمَّل

يستخدم التطبيق ترتيب الأبجد المشرقي:

| الحروف | القيم |
|---|---|
| ا ب ج د ه و ز ح ط | 1–9 |
| ي ك ل م ن س ع ف ص | 10–90 |
| ق ر ش ت ث خ ذ ض ظ غ | 100–1000 |

التطبيع المستخدم:

- `أ` و`إ` و`آ` و`ء` و`ٱ` ← `ا`
- `ة` ← `ه`
- `ئ` و`ى` ← `ي`
- `ؤ` ← `و`
- تُوحّد أشكال العرض العربية تلقائيًا؛ مثل `ﻻ` التي تُقرأ `لا`.
- الرمز القرآني `﷽` يُقرأ بصيغته الكاملة: `بسم الله الرحمن الرحيم`.
- العلامات والمسافات والحروف غير الموجودة في جدول الأبجد لا تدخل في المجموع.
- الشدة لا تضاعف قيمة الحرف.

### أمثلة مرجعية

| النص | الناتج |
|---|---:|
| بسم الله الرحمن الرحيم | 786 |
| محمد | 92 |
| فاطمة | 135 |
| داود | 15 |
| جالوت | 440 |

مثال البرج الحرفي:

```text
محمد = 92
فاطمة = 135
المجموع = 227
227 ÷ 12 → الباقي 11
النتيجة التراثية: الدلو
```

## الخصوصية

- الحسابات تُنفّذ محليًا داخل التطبيق.
- لا يتطلب التطبيق تسجيل دخول.
- لا تُرسل الأسماء أو تواريخ الميلاد إلى قاعدة بيانات خاصة بالمشروع.
- تُحفظ حالة الاستخدام محليًا على جهاز المستخدم.
- روابط المصادر الخارجية لا تُفتح إلا عند اختيار المستخدم لها.
- يرفض التطبيق فتح رابط مصدر غير موجود في قائمة المصادر المعتمدة داخل الكود.

## التثبيت على Windows

1. افتح صفحة [Releases](https://github.com/Ibradagr8/HisabJomal/releases).
2. نزّل ملف التثبيت الوحيد بصيغة `.exe`.
3. شغّل المثبّت واتبع الخطوات الظاهرة.
4. إذا ظهر تحذير Windows SmartScreen، فتحقق من أن الملف نُزّل من صفحة Releases الرسمية للمشروع. الإصدارات الحالية قد تكون غير موقعة رقميًا.

ينشئ البناء مثبّت NSIS واحدًا بصيغة `.exe` حتى لا يضطر المستخدم للاختيار بين صيغ تثبيت متعددة.

## تشغيل المشروع محليًا

### المتطلبات

- [Node.js](https://nodejs.org/) إصدار حديث؛ يستخدم البناء الآلي Node.js 24.
- [Rust](https://www.rust-lang.org/tools/install) بالإصدار المستقر.
- أدوات تطوير Tauri 2.
- على Windows: Microsoft WebView2 وأدوات البناء الخاصة بـ Visual Studio C++.
- NSIS مطلوب عند إنشاء مثبّت `.exe` محليًا.

### تثبيت الاعتمادات

```bash
npm ci
```

### تشغيل واجهة التطوير

```bash
npm run dev
```

### تشغيل تطبيق سطح المكتب أثناء التطوير

```bash
npm run tauri:dev
```

### بناء الواجهة

```bash
npm run build:desktop
```

### إنشاء حزم Windows

نفّذ الأمر التالي من Windows:

```bash
npm run tauri:build:windows
```

تظهر الملفات عادة داخل:

```text
src-tauri/target/release/bundle/nsis/
```

## أوامر المشروع

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل Vite للتطوير |
| `npm run build` | بناء نسخة الويب المستقلة |
| `npm run build:desktop` | بناء الواجهة ونسخها إلى مجلد Tauri |
| `npm test` | تشغيل اختبارات المحركات والحالة والتوافق |
| `npm run check` | تشغيل الاختبارات ثم بناء واجهة الإنتاج |
| `npm run tauri:dev` | تشغيل تطبيق سطح المكتب في وضع التطوير |
| `npm run tauri:build` | بناء حزم النظام الحالي |
| `npm run tauri:build:windows` | بناء مثبّت EXE بنظام NSIS على Windows |

## البناء الآلي والإصدارات

يوجد مسار GitHub Actions باسم **Build Windows app**:

- يمكن تشغيله يدويًا من تبويب Actions.
- يعمل تلقائيًا عند رفع وسم يبدأ بـ `v` مثل `v0.1.11`.
- يثبت Rust وNode.js وNSIS.
- يبني مثبّت EXE واحدًا بنظام NSIS.
- يرفع Artifact باسم `atlas-al-huruf-windows-exe`.
- عند التشغيل بوسم إصدار، ينشر المثبتات تلقائيًا في GitHub Releases.

مثال لإنشاء إصدار بعد مراجعة التغييرات:

```bash
git tag v0.1.11
git push origin v0.1.11
```

## التقنية والتصميم

- **Tauri 2** لتطبيق سطح مكتب خفيف.
- **Rust** لطبقة التطبيق الأصلية.
- **JavaScript** بدون إطار واجهة ثقيل.
- **Vite وesbuild** للتطوير وتجميع الواجهة.
- واجهة عربية RTL متجاوبة.
- ألوان الهوية: الأخضر الزمردي، الذهبي المعتّق، والخلفية العاجية.
- أيقونة «أطلس الحروف» مستوحاة من الزخرفة الهندسية والحروف العربية، وتستخدم اثنتي عشرة وحدة بصرية في تكوين واحد.

## الحالة الحالية

- الإصدار: `0.1.11`
- الأنظمة المستهدفة: Windows، وiPhone عبر نسخة الويب القابلة للإضافة إلى الشاشة الرئيسية.
- واجهة التطبيق: العربية.
- التطبيق يعمل محليًا دون حساب مستخدم.
- معرّف الحزمة محفوظ لضمان إمكانية ترقية النسخ السابقة.
